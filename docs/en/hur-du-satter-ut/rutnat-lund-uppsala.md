# Grid (Lund and Uppsala)

The trial is carried out in Lund and in Uppsala. At each site, 2 separate 3×3 grids of light-bucket traps for moths are set up — so two separate grids per town.

## The traps

The grid part uses the trap type **LED-Emmer standard model 2.0** from Veldshop. In practice, this trap is identical to Vlinderstichting's standard model of **LED-Emmer** (same UV specification, see [Trap types](../falltyper/oversikt.md)) used in the gradient trial, but it lacks a light sensor and has small construction differences from the Vlinderstichting model in funnel, lid, and light-module shape. The light module's wings are adapted to fit this particular funnel.

Since the UV specification is identical to the **LED-Emmer standard**, this trap type is registered as **LED-Emmer (standard)** in the app or on the website (`Ledstrip > 395-405 SMD 2835`, see [Trap types](../falltyper/oversikt.md)).
