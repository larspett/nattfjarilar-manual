# What should be reported

## Focus

- **Larger moths (macro-moths)**: noctuids, geometrids, hawk-moths etc. — this is the core of what should be counted
- **Micro-moths:** tineids, tortricids etc., this is optional. Fine to try, but harder for the app's classifier. Be extra careful to get sharp photos with the moth as large as possible in the frame if you're reporting small species.
- **Other groups** (caddisflies, mayflies, beetles, etc.): can be photographed but are currently classed as "Unknown". There are plans to be able to group these afterwards so the data becomes usable.

## Practical tips when registering

- The app lets users count animals outside the trap separately from animals in the trap. Don't do that. **To get consistent data, we count all animals (both outside and inside) as being in the trap**.
- If you photograph **the same animal twice, it counts as two individuals** — adjust the count manually if needed
- If you see **many individuals** of the same species, **take one photo and increase the count manually** instead of photographing every individual
- The app can't (yet) crop images, so **crop in your phone's camera app before uploading if needed**.
- Unsure of the species ID? **Feel free to try the apps** [ObsIdentify](https://waarneming.nl/) and [Artsorakel](https://orakel.artsdatabanken.no/), which tend to be reliable for a quick check.
- If the animals are flying around a lot and risk escaping before you've documented them, **feel free to use a net**. We've ordered large nets for all participants — they should be able to cover an entire trap and are expected to arrive in early August.

## Known issue: scientific names

Swedish taxonomy ([Dyntaxa](https://artfakta.se/sok/namn/lista), the systematic database behind Artportalen) sometimes uses different scientific names than the rest of Europe, which can cause the classifier to have trouble matching the correct species (e.g. the clay fan-foot moth). A list of the affected species is being compiled, but it may take a few weeks. The photos remain in the database and can be adjusted during the validation step.
