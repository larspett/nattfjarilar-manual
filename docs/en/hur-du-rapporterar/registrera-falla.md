# Register your trap

Before you can start reporting moths, you need to both install the ButterflyCount app and register your trap and site. This is only done once per trap, either via the web or directly in the app.

## 1. Install the ButterflyCount app

![The ButterflyCount app](../../assets/images/app/bilaga1-app-badges.png)

Download the app from wherever you normally get your apps:

- [Google Play](https://play.google.com/store/apps/details?id=uk.ac.ceh.ebms&hl=sv&gl=US)
- [App Store](https://apps.apple.com/ie/app/ebms/id1461711373)

Open the app and choose **Language** and **Country**.

Create a user account: go to **Menu**, fill in your name and password, read and accept the terms of use.

## 2. Set moth counting as the default survey

Go to:

**Menu → App → Primary Survey → Moth Survey (SPRING)**

## 3. Download species lists

Under the same settings, download the species lists **Sweden** and **EBMS moths**.

## 4. Register your trap

You can register the trap either via the web or directly in the app.

### Via the web

Go to [butterfly-monitoring.net/ebms-app](https://butterfly-monitoring.net/ebms-app).

![Login on butterfly-monitoring.net](../../assets/images/app/bilaga2-webb-banner.png)

1. Log in with the same login details as in the app.
2. Go to **My data → My moth traps → Add a site**.
3. Fill in **Country**, **Site name**, and **Location** (tap the map).
4. Choose the trap type: **LED Funnel trap**.
5. Under **Types of lamp in trap**, see the naming convention below.
6. Press **Submit**.

![My moth traps, list of registered sites](../../assets/images/app/bilaga2-webb-mina-fallor.png)

### Naming convention

If you have several traps at the same site, each trap must be registered separately, e.g. **Ängen 1**, **Ängen 2**, **Ängen 3**.

For the gradient project's four trap types, specify the light source at registration as follows (see [Trap types](../falltyper/oversikt.md) for full specifications):

| Trap type | Light source |
|---|---|
| LED-Emmer (standard) | `LED > Ledstrip > 395-405 SMD 2835` |
| LED-Emmer 2.0 Quad | `LED > Other > "395-405 Quad"` |
| EntoLight Twincolor | `LED > Other > "Entolight Twincolor"` |
| EntoLight Multicolor | `LED > Other > "Entolight Multicolor"` |

The Veldshop variant used in the grid section is registered as **LED-Emmer (standard)** with the same light source (`LED > Ledstrip > 395-405 SMD 2835`), since the UV specification is identical.

### Important: avoid "training mode"

Do **not** register in training mode, either in the app or on the website. The observations will enter the system, but you won't be able to edit them afterwards.
