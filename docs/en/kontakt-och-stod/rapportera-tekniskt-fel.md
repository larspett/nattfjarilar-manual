# Report a technical issue in the app or on the website

Please note: this page covers **technical problems in the ButterflyCount app or on butterfly-monitoring.net**, i.e. things outside our own manual. Errors or unclear points in the manual itself are best reported directly to [nattflyn@gmail.com](mailto:nattflyn@gmail.com).

## Step 1: talk to us first

Before reporting anything further, email **[nattflyn@gmail.com](mailto:nattflyn@gmail.com)** or reach out in the WhatsApp group, and describe what's happening. For two reasons:

- Many problems are already known, or can be solved directly (e.g. training mode, see [Register your trap](../hur-du-rapporterar/registrera-falla.md)).
- The app and website are used by moth recorders across Europe. If every Swedish participant reports the same thing directly to the developers, their issue list risks getting flooded, making it harder for them to spot the genuinely new problems. So we gather things up and pass on what's really needed, rather than everyone doing it separately.

## What is the GitHub issue tracker?

The app and website are developed by the UK Centre for Ecology & Hydrology (UKCEH) / Biological Records Centre, as part of the European ABLE project. They use GitHub to keep track of bugs and feature requests, just like many other development projects.

**Issue tracker**: [github.com/BiologicalRecordsCentre/ABLE/issues](https://github.com/BiologicalRecordsCentre/ABLE/issues)

Creating an "issue" there means, in practice, sending a bug report or feature request directly to the development team, visible to everyone using the system across Europe. It requires:

- A free GitHub account
- A description in English (the development team is international)
- Ideally a clear description of what went wrong, preferably with a screenshot

## Step 2: if we decide it needs to be reported further

If we jointly assess that the issue is new and needs to reach the developers, we'll help formulate the report together — either you submit it yourself with our help, or we do it for you.
