## What this project is

A field manual for a 2026 Swedish moth monitoring pilot, hosted as a public Jekyll/GitHub
Pages website at https://larspett.github.io/nattfjarilar-manual/. ~15 participants run
light traps at sites across Sweden (grid sub-project in Lund/Uppsala; 15-site
Lund-to-Abisko latitude gradient). Current version: **v0.9.1 (2026-07-27)**.

Lars B. Pettersson (lars.pettersson@biol.lu.se), Biologiska institutionen, Lunds
universitet. Contributors: Harriet Arnberg, Amanda Ernstsson, Ana Teodora Ştefan (all LU).
Funded by Naturvårdsverket, contract NV-26-076242.

## RESOLVED: Rutnät position maps (v0.9.0)

Previously the #1 open item — now done. Full technical writeup in DECISIONS.md
("Rutnät position maps — displacement approach RESOLVED"). Short version:

- All four maps (Skåne A/B, Uppland A/B) are live in rutnat-lund-uppsala.md with
  anonymized headings and security-displaced positions (`skane-a/b-public.jpg`,
  `uppland-a/b-public.jpg` in docs/assets/images/rutnat/).
- Fix for the earlier failed attempts: export from QGIS centered directly on the
  *displaced* coordinates (not the real ones) at proper resolution; scale bar drawn by
  Claude via detecting the visible 1×1km reference square directly in the image (looks
  for long unbroken dark line-runs vs. text, which breaks into short segments) — gives
  exact px-per-meter calibration with no coordinates/projection needed.
- Uppland A/B's 3×3 grid is generated by bilinear interpolation directly from the
  official 1km survey square's own four corners (EPSG:3006/SWEREF99TM, no lat/lon
  conversion) — not real registered trap GPS, which is still an open item (see below).
- Original real-position images kept for Lars's bookkeeping in
  docs/assets/images/precise-maps/, gitignored, never pushed publicly.
